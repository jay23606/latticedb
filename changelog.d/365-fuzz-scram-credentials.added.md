Two fuzz targets for the authentication input path, `scram_exchange` and `credential_file`, run in the nightly, weekly and 24-hour matrices. `scram_exchange` sends SASL frames through a session selected the way a host selects it and checks that no input completes authentication, that a failed exchange closes the connection, and that no query reaches the handler. `credential_file` feeds bytes to the SCRAM account file parser and checks that each accepted account selects its own principal and an absent name selects none. Seeds cover valid and malformed frames and account files. Not done: the `subscribe_host` and `tls_pem` targets from #365, and any fuzz run that reaches a verified proof, which needs a client-side HMAC the fuzz crate does not depend on.
