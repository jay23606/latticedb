Added end-to-end tests for MCP over HTTP in `lattice-e2e`: two principals call `POST /mcp` through the real gateway over loopback sockets. They check the grants (a principal without a write grant is refused), a write that the other principal reads back, a version conflict, the scope refusal, and the 401 for a missing credential. A `lattice_subscribe` cursor chain over a seeded history yields every write exactly once, in order, and resuming from any cursor gives exactly the writes after it. See `docs/mcp-v0.md` (HTTP transport and Subscribe).
