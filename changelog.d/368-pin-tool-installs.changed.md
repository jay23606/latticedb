Every `taiki-e/install-action` step in the workflows now names an exact tool version: `cargo-deny@0.20.2` in the cancel-loom, io-probe, nightly-build and release workflows, and `typos@1.51.1` in the PR gate. `tools/check_install_action_pins.py` fails on a `tool:` entry without an exact `name@X.Y.Z` version, and its unit tests run it over `.github/workflows`. Dependabot does not read these pins, so a new tool version is a reviewed edit to a workflow.
