`lattice watch table/NAME` checks its arguments and holds the event line format and the rule that an event is acknowledged only after its line is printed. It accepts only a `ws://` URL on a loopback address (there is no TLS on the client yet) and reads the token from an owner-only file or from standard input, never from the command line. It does not connect yet: the socket transport, the reconnect loop and the end-to-end test come with the e2e harness (#540).
