Agent task board: `integrations/board` is a POSIX shell helper and a schema that let one maintainer agent and its subagents add, claim, note, decide on and close tasks, and poll an event log with `board since`. It uses only the alpha SQL subset through `psql`, and a claim is won by exactly one of several concurrent claimers. Not done: a push channel, `count(*)` and other aggregates, sequences, and text with a backslash. `integrations/board/CONVENTIONS.md` lists the limits and the workarounds.
