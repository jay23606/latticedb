The sync gateway serves TLS on its port when `--tls-cert` and `--tls-key` are given, the same files and key rules as the PostgreSQL listener. A non-loopback `--gateway-listen` now needs those files and `--gateway-tokens`, and latticed refuses to start otherwise; plaintext is for loopback development only. The handshake runs under `--gateway-handshake-timeout-ms`. Idle deadlines are still open.
