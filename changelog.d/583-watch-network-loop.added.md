`lattice watch table/NAME` now connects to the sync gateway on a loopback address, subscribes to the table and prints each change as `CURSOR AUTHOR TABLE KEY OPERATION`. Each event is printed, then acknowledged, then its cursor saved, so a crash re-prints an event and never skips one. `--cursor-file FILE` keeps the cursor in an owner-only file (mode 0600) in an existing private directory, refuses a file that does not hold one cursor, and refuses a second watch on the same file. A dropped connection is retried from the last saved cursor with a doubling wait; three failures in a row that deliver nothing stop the watch, and a refused token or a policy close stops it at once. Not done: the SDK's jittered backoff, TLS on the client and an end-to-end test against a live gateway.
