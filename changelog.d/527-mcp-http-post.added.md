The experimental sync gateway serves the MCP tools (`lattice_read`, `lattice_write`, `lattice_subscribe`) at `POST /mcp` on its port. A request carries a bearer token and is answered as the principal that token verifies; the body cannot name another one. The endpoint refuses a foreign `Host`, any `Origin`, a body that is not `application/json`, and a body over 1 MiB. It is loopback only and has no TLS, and there is no stdio transport. See `docs/mcp-v0.md` (HTTP transport).
