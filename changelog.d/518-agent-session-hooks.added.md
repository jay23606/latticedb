Session hooks for the board in `integrations/claude-code/hooks`: a SessionStart hook prints a bounded digest of open tasks and saves the board cursor, and a UserPromptSubmit hook shows the events since that cursor. Both fail open, bound their board calls in time and output, strip control characters from stored text, frame it with a random nonce, and never write to the board. The cursor is the board head, owner-only under `.lattice/` in the project. Not done: session presence, the installer and the stdio proxy.
