Added `lattice mcp`, a stdio proxy to the gateway's `POST /mcp` endpoint. It reads one JSON-RPC message per line from standard input, sends each to a loopback `http://` URL with the bearer token from an owner-only file (or the first line of standard input), and writes each reply as one line on standard output. A message over 1 MiB is refused with a JSON-RPC error, and a token on the command line is refused. It has no TLS yet, so a remote gateway is not reachable from it. See `crates/lattice-cli/README.md` and `docs/mcp-v0.md` (stdio proxy).
