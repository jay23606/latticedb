`lattice-sdk` gains `reconnect`: `Supervisor`, a pure decision over `Backoff` for a connection that ended. It returns a retry delay, or stops for good: when the server refuses the client's version, cursor, scope or frames (a repeat would be refused again), when the transport refuses the credentials, when the application closed the client, or when an optional bound on consecutive transient failures is reached. The backoff returns to its first window only after an event is delivered, never after a connect or a handshake frame. The driver that waits, opens a new transport and calls `SyncClient::reconnect` is not part of this change.
