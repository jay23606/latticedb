MCP tool errors say what to do next. A call on a scope the server does not serve is still `40302`, but the message names the served scope: `scope denied; this server serves scope "default"`. A `table_shape` answer carries a `hint` with the columns a key/value table needs. The `scope` and `lattice_subscribe` descriptions in `tools/list` say to use the served workspace (normally `default`) and that `after` is the optional `next_cursor` of a previous reply. Other codes and messages are unchanged, and no grant is named.
