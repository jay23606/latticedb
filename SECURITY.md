# Security policy

Report vulnerabilities privately using GitHub's "Report a vulnerability" (private security advisory)
on this repository. A dedicated security mailbox will be added once the project has a domain.

Include a description, a proof of concept, the estimated impact and a suggested fix if you have one.
We acknowledge reports within three business days and aim to publish a fix and advisory within
ninety days. Please do not open public issues for vulnerabilities. There is no bug bounty yet.
