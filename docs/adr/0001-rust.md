# ADR 0001: Rust as the implementation language

Status: accepted

## Context

Lattice is a database. It needs predictable latency (no garbage collector pauses), io_uring access, memory safety, in-process inference for the optional models plugin, and derive macros for the schema layer.

## Decision

Implement the server, engines, schema compiler and tooling in Rust. Client SDKs for other languages are generated.

## Consequences

Rust expertise is required of contributors. We gain memory safety, no GC pauses and strong typing for typestate and proof-token patterns. Go was considered: faster to write, but GC jitter and cgo cost for inference.
