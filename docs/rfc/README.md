# RFCs

Cross-cutting changes (wire protocol, on-disk format, LSL grammar, policy model) start as an RFC.
Copy `TEMPLATE.md` to `NNNN-title.md`, open a pull request, and keep it open for the comment period
(at least seven days). When accepted, record the decision as an ADR and fill in `Decision ADR:`.
`cargo xtask rfc lint` validates the required fields.
