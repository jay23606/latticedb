# Code of conduct

We want Lattice to be a welcoming project. Be respectful, assume good intent, give and accept
constructive feedback, and do not harass, discriminate or demean. Maintainers may remove content
and restrict participation for behaviour that breaks these rules. Report concerns privately to a maintainer
(see GOVERNANCE.md), for example through a private GitHub security advisory or a direct message.
Reports are handled confidentially, and the reporter is told the outcome.
