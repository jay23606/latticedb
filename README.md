# Lattice

One open source database for a whole dev team: work items, docs, specs, designs and deployments,
queryable by text, meaning and time, with agents as permission-bound teammates.

Status: Phase 0 and Phase 1 in progress. See `docs/spec/README.md` for the phased plan,
`docs/ARCHITECTURE.md` for the design and `docs/conventions.md` for the rules.

```bash
cargo xtask ci        # the same checks the pull-request workflow runs
cargo xtask backlog seed
```
